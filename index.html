Approach

How I work.

  1. Understand the problem

    Start with who uses it and what they need to do, before choosing tools.

  2. Build something real

    Connect the interface to working behaviour early, so you see progress rather than mockups.

  3. Test on small screens

    Start from the phone layout and enhance upward, then check links and keyboard use.

  4. Say what's in scope

    Agree deliverables clearly, and report plainly on what is done and what isn't.
